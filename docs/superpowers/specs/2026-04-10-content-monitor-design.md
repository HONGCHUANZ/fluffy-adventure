# 内容监控工具 — 前端原型设计

> 日期：2026-04-10
> 状态：待实现
> 技术栈：Next.js (App Router) + Tailwind CSS

## 1. 项目概述

构建一个内容监控工具的前端原型页面，用于按分类管理不同关键词/博主的内容监控任务。支持多平台、多关键词、多博主的监控配置，通过 AI 对采集到的热门内容进行分析，产出选题报告与洞察建议。

**目标用户**：内容运营人员
**视觉风格**：深色专业风格，深色背景配合亮色数据高亮

## 2. 整体布局

采用 **左侧边栏 + 主内容区** 布局：

```
┌──────────────┬─────────────────────────────────────────┐
│  LOGO        │  Tab 导航栏（内容 | 选题报告 | 监控设置）│
│              ├─────────────────────────────────────────┤
│  ▼ 分类A  ●  │  平台标签行（可横向滚动）                │
│    分类B     │  横向日期卡片（带数据 badge）            │
│    分类C     ├─────────────────────────────────────────┤
│              │                                         │
│  + 新建分类  │  主内容区域（卡片列表/报告/表单）       │
└──────────────┴─────────────────────────────────────────┘
```

### 2.1 左侧边栏
- 宽度 240px，可折叠至 64px（仅图标）
- 当前分类高亮显示
- 每个分类显示名称 + 最近运行时间（如 "今天 08:30"）
- 运行中状态用绿色圆点 ● 表示
- 底部 "+ 新建分类" 按钮
- 折叠时仅保留分类首字 + 运行状态点

### 2.2 主内容区 Tab 导航
- 三个 Tab：内容 | 选题报告 | 监控设置
- 切换分类时重置到"内容" Tab

## 3. Tab 1：内容

### 3.1 平台筛选
- 标签按钮平铺展示（非下拉选择框）：`[全部] [抖音] [小红书] [微博] [B站] [快手]`
- 支持多选，已选标签高亮
- "全部"标签在有其他标签选中时变灰
- 点击平台标签即时过滤下方内容列表

### 3.2 时间选择
- **方案：横向滚动日期卡片**
- 每天一张卡片，横向排列可滚动，左右有箭头指示
- 每张卡片显示：日期 + 内容条数 badge
- 当天用蓝色圆点标记
- 无数据日期灰显不可点击
- 默认选中最新有数据的一天
- 点击日期卡片即时更新下方内容列表

### 3.3 内容列表
- 按热度降序排列
- 每个内容卡片展示：
  - 热度值（🔥 数字）
  - 平台标识
  - 采集时间
  - 标题
  - 博主名 + 粉丝量
  - 互动数据（点赞、评论、转发/收藏，按平台差异展示图标）
- 卡片 hover 时显示"查看详情"可展开更多元数据
- 深色风格：卡片 bg `#1e1e2e`，悬停 `#2a2a3e`

## 4. Tab 2：选题分析与报告

### 4.1 视图切换
- 顶部两个按钮式切换（分段控制器）：`[按日期查看报告] [按选题汇总]`
- 不是 Tab，而是同一数据的不同展现维度

### 4.2 按日期查看报告（默认视图）
- 最新报告默认展开，历史报告折叠
- 顶部有"⚡ 运行今日分析"按钮，点击显示 loading 进度条 → 完成后刷新
- 每个日期报告卡片包含：
  - **昨日热点回顾**：当日 Top N 热门话题列表
  - **选题建议**：每个选题包含方向标题 + 选题简介（为什么做、爆点、增长空间）+ 来源平台统计

### 4.3 按选题汇总
- 默认时间范围：近 7 天，可选 7/14/30 天
- 将多日报告中重复出现的选题合并展示
- 每个选题卡片包含：
  - 方向标题
  - 首次出现日期
  - 热度趋势（↑↑↑ / ↑↑ / ↑）
  - 选题简介（为什么做、爆点、增长空间）
  - 来源报告日期列表

## 5. Tab 3：监控设置

### 5.1 监控平台
- 卡片式开关展示所有可用平台
- 点击切换 ✅/❌ 状态

### 5.2 对标关键词
- 标签输入框（tag input），输入后回车生成标签
- 点击 × 删除
- 支持批量粘贴（逗号/换行分隔自动拆分）

### 5.3 对标博主/账号
- 小型表格列表：博主名称、平台、操作（删除）
- 添加时弹窗选择平台 + 输入博主名

### 5.4 运行设置
- 运行频率：每天一次（固定，不可改）
- 运行时间：可选（默认 08:00）
- AI 分析引擎：可选（默认 OpenAI ChatGPT）
- 底部"保存设置"和"重置"按钮

## 6. 数据与假数据

前端为原型阶段，所有数据使用内置假数据，不涉及后端 API。

### 6.1 假数据包含
- **分类**：claudecode 的选题监控、Vibecoding 的选题监控
- **平台**：抖音、小红书、微博、B站、快手
- **内容**：每条包含标题、平台、博主、粉丝量、热度、互动数据、采集时间，覆盖近 5 天
- **选题报告**：3 天的报告数据，每天包含 3-5 个选题建议
- **关键词**：AI编程、VibeCoding、Claude、Cursor、AI建站
- **博主**：@TechDaily（抖音）、@CodeWithMe（小红书）、@AIInsights（B站）、@VibeCodeHub（抖音）

## 7. 设计规范

### 7.1 色彩
- 背景：`#0f0f1a`（主背景）、`#1a1a2e`（区域背景）
- 卡片：`#1e1e2e`（默认）、`#2a2a3e`（悬停）
- 文字：`#e0e0e0`（主文字）、`#a0a0b0`（次要文字）
- 强调色：`#6c63ff`（紫色系按钮/高亮）
- 成功/运行：`#22c55e`
- 热度：`#ff6b6b`

### 7.2 交互原则
- 所有筛选/切换操作即时生效，无需额外确认
- 默认展示最新/最相关的数据
- 减少用户思考成本，操作反馈即时可见
